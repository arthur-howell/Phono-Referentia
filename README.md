# PHONO REFERENTIA

### *Cartridge Testing for Phono Education*

**Phono Referentia** is an ongoing reference project created to document, compare, and demonstrate the performance characteristics of phono cartridges and styli using controlled, repeatable source material.

Rather than relying on commercially released music—which introduces licensing restrictions and inconsistent test material—**Phono Referentia** uses purpose-built original recordings designed specifically to expose different aspects of cartridge and stylus performance.

---

## The Reference Discs

A new **Phono Referentia Reference Disc** is planned periodically, with each release concentrating on a different group of playback characteristics.

Each disc contains original music specifically composed and arranged around its testing objectives.

### Reference Disc I — Dynamics & Vocals (2026)

Future editions may explore subjects including:

- Frequency extension
- Instrumentation
- Stereo imaging
- Transient response
- Tracking performance
- Complex passages
- Other characteristics relevant to phono reproduction

> **The intention is not to create synthetic test tones disguised as music.**

These are complete musical compositions designed to remain enjoyable while containing deliberately selected characteristics useful for critical listening and comparison.

---

## Reference Methodology

The original digital masters establish the project's baseline.

Those masters are cut to a physical reference record. That same physical record is then played using each cartridge or stylus under evaluation.
